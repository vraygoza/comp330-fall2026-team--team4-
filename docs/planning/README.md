## How the Pieces Connect
1. [Requirements](../requirements/requirements.md) define what the bot must do, with IDs (FR-1, NFR-1).
2. The [Scope Statement](scope.md) says which requirements are committed, optional, or out of scope for Cycle 1.
3. Traceability maps each requirement ID to GitHub Issues, owners, and estimates.
4. Estimates, the schedule, and team commitments are built from those Issues.
5. The risk register and [Open Questions](../requirements/open-questions.md) show where uncertainty is highest and what would trigger re-estimation.
