# AI Usage Policy

## Policy Overview
This document outlines the team's policy on the use of AI tools (including GitHub Copilot, ChatGPT, Claude, etc.) in the development process.

## Approved AI Tools
- GitHub Copilot
- ChatGPT
- Other: [Add as needed]

## Permitted Uses
- Code suggestions and completions
- Documentation generation
- Testing and debugging assistance
- Research and brainstorming

## Prohibited Uses
- Copying entire solutions without understanding
- Using AI to bypass learning objectives
- Submitting AI-generated work without attribution

## Attribution Requirements
All AI-assisted code must be:
1. Clearly marked with comments indicating AI assistance
2. Documented in commit messages
3. Reviewed and understood by the developer before submission

## Academic Integrity
- Team members must understand and be able to explain all code submitted
- AI tools should enhance productivity, not replace learning
- Always disclose AI assistance to instructors when required

## Regular Review
This policy will be reviewed and updated as needed throughout the project.
