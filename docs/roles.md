# Team Roles and Responsibilities

## Role Definitions

### Project Manager
- Oversees project timeline and deliverables
- Coordinates between team members
- Manages stakeholder communication

### Developer
- Implements features and functionality
- Writes and reviews code
- Participates in design decisions

### Quality Assurance / Tester
- Creates and executes test plans
- Identifies and documents bugs
- Ensures code quality standards

### Documentation Specialist
- Maintains project documentation
- Creates user guides and technical specs
- Manages meeting notes
